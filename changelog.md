## v2.0.0 - 2026-04-02
* The `GetWheelchairUse()` method has been removed from both `ClientFacingActivity` and `ClientFacingProfile`. Callers that reference these methods must update their code — use direct field access (e.g., `.WheelchairUse`) as a replacement.
* The SDK now supports three new query expression types: `DerivedReadinessColumnExpr` (for readiness-related columns such as sleep score, recovery score, and strain zone), `AwakeningsValueMacroExpr` (for the "awakenings" value macro), and `InsulinInjectionTimeseriesExpr` (previously represented as an `IntervalTimeseriesExpr` variant).
**Breaking changes:** All implementations of `AggregateExprArgVisitor`, `QueryGroupByItemVisitor`, and `QuerySelectItemVisitor` must now implement three additional Visit methods: `VisitDerivedReadinessColumnExpr`, `VisitAwakeningsValueMacroExpr`, and `VisitInsulinInjectionTimeseriesExpr`. The `IntervalTimeseriesExprTimeseriesInsulinInjection` constant has been removed — use `InsulinInjectionTimeseriesExpr` instead. The `Placeholder` struct no longer exposes `GetPlaceholder()` or `SetPlaceholder()`; `placeholder` is now a literal field accessed via `Placeholder()`. `QueryBatch.Timeframe` and `QueryBatch.Queries` are now always serialized (omitempty removed).
* **Breaking changes to lab report parsing types:**
* `ParsingJob.JobId` field, `GetJobId()`, and `SetJobId()` have been removed. A new `FailureReason` field (`*ParsingJobFailureReason`) has been added in its place, with a corresponding `GetFailureReason()` and `SetFailureReason()` method.
* `ResultMetadata` fields `PatientFirstName`, `PatientLastName`, `Dob`, and `LabName` have changed from `string` to `*string` (optional). Callers must dereference these fields and update any calls to the corresponding `Set*` methods to pass `*string`.
* `BodyCreateLabReportParserJob.File` has changed from `io.Reader` to `[]io.Reader` to support multiple files.
* New `ResultMetadataGender` field added to `ResultMetadata`, along with new `ParsingJobFailureReason` and `ResultMetadataGender` enum types.
* Several exported types have been removed from the lab tests package: `BiomarkerResult`, `ClinicalInformation`, `FailureType`, `LabResultsMetadata`, `LabResultsRaw`, `LabResultsRawResults`, `MissingBiomarkerResult`, `OrderLowLevelStatus`, `ParentBiomarkerData`, `SampleData`, `SampleDataDateCollected`, `SampleDataDateReceived`, `SampleDataDateReported`, and `UtcTimestampWithTimezoneOffset`. Callers referencing these types must be updated. In addition, `AppointmentPscLabs` has changed from a type alias (`= string`) to a named string type, which may break code that assigns raw `string` values without conversion. New capabilities include Sonora Quest lab support (`AppointmentProviderSonoraQuest`, `ClientFacingLabsSonoraQuest`), a new `LabTestsBookPscAppointmentRequest` type with idempotency key support, appointment notes and async confirmation fields on booking/reschedule requests, and several new optional filter fields across order and marker query requests.
* Several breaking changes have been made to bulk operation and link request types. The `TeamId` field and `SetTeamId` method have been removed from `BulkExportConnectionsBody`, `BulkImportConnectionsBody`, `BulkPauseConnectionsBody`, `BulkTriggerHistoricalPullBody`, and `LinkListBulkOpsRequest`. The exported types `LinkBulkExportRequestTeamId`, `LinkBulkImportRequestTeamId`, `LinkBulkPauseRequestTeamId`, `LinkBulkTriggerHistoricalPullRequestTeamId`, and `LinkListBulkOpsRequestTeamId` have been removed entirely — update any code referencing these types or methods. New provider constants `ManualProvidersSamsungHealth` and `PasswordProvidersTandemSource` are now available, `ClientFacingSleep` gains a `RecoveryReadinessScore` field, and `ManualConnectionData` gains `VitalIosSdkVersion`, `VitalAndroidSdkVersion`, and `GrantedPermissions` fields.
* Several breaking changes are included in this release:
* `UserInfo.Address` and `UserInfoCreateRequest.Address` fields now use `*UserAddress` instead of `*Address`. Callers must update references from `*Address` to `*UserAddress`.
* `UserRefreshSuccessResponse.Success` is no longer an exported struct field. The exported `GetSuccess()` and `SetSuccess()` methods have been removed; use the new `Success()` method instead.
* `BookPscAppointment` (in `labtests`) now accepts `*LabTestsBookPscAppointmentRequest` instead of `*AppointmentBookingRequest`. Update call sites accordingly.
* New capabilities also added: three new top-level service clients (`Compendium`, `LabAccount`, `OrderTransaction`), new `DeliveryMode`, `DeliveryForm`, and `BolusPurpose` fields on `ClientFacingInsulinInjectionSample`, a new `ClientFacingDeviceSourceTypeInsulinPump` constant, and support for form URL-encoded request bodies.
* The SDK now includes support for lab compendium search and conversion. New types `SearchCompendiumBody`, `ConvertCompendiumBody`, `SearchCompendiumResponse`, and `ConvertCompendiumResponse` are available, along with supporting model types (`CanonicalCandidate`, `PerLabCandidate`, `RelatedCandidate`, `ProviderIdConversionResponse`) and enums (`CompendiumSearchLabs`, `SearchMode`) for working with canonical lab test matching and cross-lab provider ID conversion.
* The SDK now includes two new API client packages: `compendium` (with `Search` and `Convert` methods for lab compendium operations) and `labaccount` (with `GetTeamLabAccounts` for retrieving team lab accounts). New types `ClientFacingLabAccount`, `GetTeamLabAccountsResponse`, `LabAccountStatus`, `LabAccountDelegatedFlow`, and `UsState` are available to support these endpoints. A new `insulin_pump` source type has also been added to ECG and menstrual cycle source type enums.
* The SDK now includes a new `ordertransaction` package providing access to order transactions via `GetTransaction`, `GetTransactionResult`, and `GetTransactionResultPdf` methods. Two new types, `GetOrderTransactionResponse` and `OrderSummary`, are available in the root package to represent transaction data. A new `insulin_pump` source type (`ClientFacingSleepCycleSourceTypeInsulinPump`) has also been added to the sleep cycle source type enum.
