## v2.0.0 - 2026-03-30
* The SDK now supports querying derived readiness data including chronotype, sleep score, recovery metrics, and strain information through the new DerivedReadinessColumnExpr. Additionally, insulin injection timeseries data can now be queried with detailed delivery information using the new InsulinInjectionTimeseriesExpr.
* The SDK now supports detailed failure reasons for lab report parsing jobs through the new `FailureReason` field on `ParsingJob`. The `ResultMetadata` struct has been updated to make patient information fields optional and includes a new `Gender` field. Note that the `JobId` field has been removed from `ParsingJob` - existing code referencing this field will need to be updated.
* The SDK now supports idempotency for PSC appointment booking through new `IdempotencyKey` and `IdempotencyError` fields. Appointment notes can now be added when booking, rescheduling, and are included in appointment responses. Async confirmation is available for appointment booking with configurable timeout options. Additional enhancements include support for Sonora Quest labs, new filtering options with `LabSlug` and `AllowStale` parameters, and new fields like `OrderTransactionId` and `AccessNotes` across various request types.
* The SDK removes deprecated `team_id` fields from bulk operations and adds support for Samsung Health and Tandem Source providers. The `ManualConnectionData` struct now includes SDK version tracking and granted permissions fields.
* The SDK now supports detailed insulin pump data tracking with new delivery modes (basal/bolus), delivery forms (standard/extended), and bolus purposes (meal/correction/mixed/unknown). A new UserAddress model replaces the generic Address type for user information, providing better type safety. Lab report parsing now supports multiple file uploads, and new client modules are available for Compendium, LabAccount, and OrderTransaction operations.
* New compendium data types added to support lab test search and provider ID conversion functionality. The SDK now includes comprehensive types for canonical candidate searches, per-lab result mapping, and cross-lab provider ID conversion.
* New compendium client available for healthcare data search and conversion operations. New lab account client provides access to laboratory partnership management. The SDK now supports "insulin_pump" as a source type for electrocardiogram and menstrual cycle data.
* New order transaction API client available with methods for retrieving transaction details, lab results, and PDF reports. Added insulin pump as a new source type for sleep cycle data.
