## v2.0.0 - 2026-03-30
* The SDK now supports derived readiness metrics and insulin injection timeseries data. New `DerivedReadinessColumnExpr` provides access to recovery scores, stress metrics, strain scores, and chronotype information. New `InsulinInjectionTimeseriesExpr` enables tracking of insulin delivery with detailed fields for delivery modes, forms, and bolus purposes.
* The SDK now supports uploading multiple files per lab report parsing job. Added structured failure reason types (ParsingJobFailureReason) for better error handling, and made patient metadata fields optional in parsing results. The ParsingJob.JobId field has been removed.
* New appointment booking enhancements include appointment notes, async confirmation with configurable timeouts, and idempotency support for PSC bookings. Lab test creation now supports lab account ID and lab slug fields. Address models now include access notes for delivery coordination. Added Sonora Quest as a new provider option.
* Breaking changes to bulk operations API: TeamId parameters have been removed from all bulk operations endpoints (BulkExportConnectionsBody, BulkImportConnectionsBody, BulkPauseConnectionsBody, BulkTriggerHistoricalPullBody). Several struct fields that were previously optional are now required, including Address in CreatePayorBody and shipping/patient details in testkit operations. New support for Samsung Health and Tandem Source providers, plus SDK version tracking for iOS/Android manual connections.
* The SDK now supports insulin pump devices with new delivery modes, forms, and purposes for insulin injection data. New client modules are available for Compendium, LabAccount, and OrderTransaction operations. The UserAddress type provides more specific address handling for user information.
* New compendium API types available for laboratory test search and conversion. The SDK now supports searching for lab tests across providers, converting tests between different laboratory providers, and working with canonical test identifications through new types including ConvertCompendiumBody, SearchCompendiumBody, CanonicalCandidate, and related response structures.
* The SDK now supports lab account management and compendium search operations. New `compendium.Client` provides `Search()` and `Convert()` methods for lab test operations, while the new `labaccount.Client` offers `GetTeamLabAccounts()` for managing lab accounts. Additionally, "insulin_pump" is now supported as a source type for electrocardiogram and menstrual cycle data.
* The SDK now supports order transaction management with new methods to retrieve transaction details, fetch lab results, and download PDF reports. The `OrderTransaction` client provides `GetTransaction()`, `GetTransactionResult()`, and `GetTransactionResultPdf()` methods. Additionally, a new `insulin_pump` source type is now available for sleep cycle data.
