## v2.0.0 - 2026-03-27
* New support for querying derived readiness metrics (sleep score, recovery score, stress score, etc.) and insulin injection timeseries data. The SDK now includes DerivedReadinessColumnExpr and InsulinInjectionTimeseriesExpr types for enhanced health data analysis capabilities.
* Breaking changes to lab report parsing: The `GetJobId()` method has been removed from `ParsingJob`. Several `ResultMetadata` fields (`PatientFirstName`, `PatientLastName`, `Dob`, `LabName`) are now optional pointer types - existing code must handle nil values. The `File` field in `BodyCreateLabReportParserJob` now accepts multiple files via `[]io.Reader`. New features include failure reason tracking via `ParsingJobFailureReason` enum and optional gender field in metadata.
* The SDK now supports enhanced appointment booking with idempotency keys, asynchronous confirmation handling, and appointment notes. Lab test creation and filtering have been expanded with new parameters for lab accounts, slugs, and transaction IDs. Added support for Sonora Quest as a lab provider and new access notes fields for addresses.
* The SDK now supports Samsung Health manual connections and Tandem Source password-based connections. JSON serialization has been improved for request body structs to handle explicit field tracking. Several struct fields that were previously optional are now required in JSON serialization.
* The SDK now supports enhanced biomarker result processing with new BiomarkerResult and MissingBiomarkerResult types, lab report parsing job events, order transaction management, and expanded address fields including access notes. New provider constants and order status values have been added for better lab workflow tracking.
* The SDK now supports enhanced insulin delivery tracking with new fields for delivery mode (basal/bolus), delivery form (standard/extended), and bolus purpose (meal/correction/mixed). New lab management capabilities are available through Compendium, LabAccount, and OrderTransaction clients. The UserAddress type replaces the generic Address type for improved type safety in user profile management.
* New compendium module available for lab test search and cross-lab conversion. The module includes types for searching canonical lab test mappings across providers and converting test identifiers between different lab systems.
* The SDK now supports the Vital Compendium API for searching and converting health data through the new `compendium` package. Lab account management is available via the new `labaccount` package with the `GetTeamLabAccounts()` method. Additional source type "insulin_pump" is now supported for ECG and menstrual cycle data.
* The SDK now includes a new OrderTransaction client for managing lab order transactions. Three new methods are available: `GetTransaction()` for retrieving transaction details, `GetTransactionResult()` for accessing results, and `GetTransactionResultPdf()` for downloading PDF reports. The SDK also adds support for insulin pump devices as a sleep cycle source type and includes a new `Bytes()` utility function for creating byte slice pointers.
