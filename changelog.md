## v2.0.0 - 2026-03-31
* New query expression types added: DerivedReadinessColumnExpr for readiness metrics, InsulinInjectionTimeseriesExpr for insulin injection data, and AwakeningsValueMacroExpr for sleep awakening analysis. The SDK now supports recovery_readiness_score field in sleep queries and includes derived_readiness index type for enhanced health data querying.
* Breaking changes to lab report parsing: The `JobId` field has been removed from `ParsingJob`. Several `ResultMetadata` fields (`PatientFirstName`, `PatientLastName`, `Dob`, `LabName`) are now optional pointer types - existing code accessing these fields must be updated to handle nil values. The SDK now supports structured failure reasons via the new `ParsingJobFailureReason` enum and `FailureReason` field, and adds support for gender metadata.
* The SDK now supports creating custom lab tests with lab-specific configurations, adding clinical notes to orders, and enhanced appointment booking with async confirmation options. New filtering capabilities include lab-specific marker queries and transaction-based order filtering. Address types now support access notes for delivery instructions, and Sonora Quest is added as a supported lab provider.
* Breaking changes to bulk operations API - team ID parameters have been removed from all bulk endpoints (export, import, pause, trigger historical pull). The SDK now includes new sleep recovery metrics, Samsung Health and Tandem Source provider support, and enhanced manual connection tracking capabilities.
* The SDK now includes enhanced insulin injection data with delivery mode, form, and bolus purpose fields. A new UserAddress type provides structured address handling, replacing the generic Address type in user information structures. New client packages are available for Compendium, LabAccount, and OrderTransaction operations. The SDK also adds support for insulin pump devices and form URL encoded requests.
* The SDK now supports laboratory test compendium operations with new types for searching and converting lab test data across multiple providers. New functionality includes `ConvertCompendiumBody`, `SearchCompendiumBody`, and related response types for comprehensive lab test management.
* New compendium API client with Search() and Convert() methods for medical data processing. New lab account management client with GetTeamLabAccounts() method. Added insulin pump as a source type for electrocardiogram and menstrual cycle data.
* New order transaction client available with methods to retrieve transaction details, results, and PDF reports. The SDK also adds support for insulin pump as a sleep cycle source type.
