## v2.0.0 - 2026-04-09
* The `GetWheelchairUse()` accessor methods have been removed from `ClientFacingActivity` and `ClientFacingProfile`. Callers that used these methods should access the `WheelchairUse` field directly (e.g., `obj.WheelchairUse`) instead.
* Three new query expression types are now available: `DerivedReadinessColumnExpr` (with a `DerivedReadiness` enum covering date, chronotype, sleep_score, recovery_score, recovery_zone, stress_score, strain_score, and strain_zone), `AwakeningsValueMacroExpr`, and `InsulinInjectionTimeseriesExpr`. The visitor interfaces `AggregateExprArgVisitor`, `QueryGroupByItemVisitor`, and `QuerySelectItemVisitor` each require three new `Visit*` methods — existing implementations of these interfaces must add `VisitDerivedReadinessColumnExpr`, `VisitAwakeningsValueMacroExpr`, and `VisitInsulinInjectionTimeseriesExpr` to compile. Additionally, `IntervalTimeseriesExprTimeseriesInsulinInjection` has been removed in favour of the dedicated `InsulinInjectionTimeseriesExpr` type.
* **Breaking changes** to lab report parsing types:
* **`ParsingJob`**: The `JobId` field and its `GetJobId()`/`SetJobId()` methods have been removed. A new optional `FailureReason` field (type `*ParsingJobFailureReason`) has been added with `GetFailureReason()`/`SetFailureReason()` accessors and a new `ParsingJobFailureReason` enum (`InvalidInput`, `LowQuality`, `NotEnglish`).
* **`ResultMetadata`**: `PatientFirstName`, `PatientLastName`, `Dob`, and `LabName` are now `*string` (pointer) instead of `string`; all corresponding getters and setters have updated signatures. A new `Gender` field of type `*ResultMetadataGender` has been added, along with a new `ResultMetadataGender` enum (`Male`, `Female`, `Other`).
* **`BodyCreateLabReportParserJob`**: The `File` field has changed from `io.Reader` to `[]io.Reader` to support multi-file uploads.
* Consumers must dereference the newly-pointer fields and remove any references to the deleted `JobId` field before upgrading.
* Several breaking changes have been made to bulk operation request types: the `TeamId` field and `SetTeamId` method have been removed from `BulkExportConnectionsBody`, `BulkImportConnectionsBody`, `BulkPauseConnectionsBody`, `BulkTriggerHistoricalPullBody`, and `LinkListBulkOpsRequest`. The corresponding `TeamId` enum types (`LinkBulkExportRequestTeamId`, `LinkBulkImportRequestTeamId`, `LinkBulkPauseRequestTeamId`, `LinkBulkTriggerHistoricalPullRequestTeamId`, `LinkListBulkOpsRequestTeamId`) have also been removed. New additions include `ManualProvidersSamsungHealth` and `PasswordProvidersTandemSource` provider constants, a `RecoveryReadinessScore` field on `ClientFacingSleep`, and `VitalIosSdkVersion`, `VitalAndroidSdkVersion`, and `GrantedPermissions` fields on `ManualConnectionData`.
* The SDK now includes new types and event kinds for lab report parsing jobs (`ClientFacingLabReportParsingJobCreatedEvent`, `ClientFacingLabReportParsingJobUpdatedEvent`), order transactions (`ClientFacingOrderTransaction`, `ClientFacingOrderInTransaction`), and structured lab results (`BiomarkerResult`, `LabResultsRaw`, `SampleData`, `PerformingLaboratory`). `ClientFacingOrder` gains `ClinicalNotes`, `Origin`, `LastEvent`, and `OrderTransaction` fields; `Address` and patient address types gain an `AccessNotes` field. New enums `OrderOrigin`, `OrderLowLevelStatus`, `OrderStatusDetail`, and `OrderTransactionStatus` are also available.
* The SDK now includes three new sub-clients: `Compendium`, `LabAccount`, and `OrderTransaction`, accessible from the root `Client`.
* `ClientFacingInsulinInjectionSample` gains three new optional fields — `DeliveryMode`, `DeliveryForm`, and `BolusPurpose` — along with their corresponding enum types, and a new `ClientFacingDeviceSourceTypeInsulinPump` constant has been added.
**Breaking changes:** `UserInfo.Address` and `UserInfoCreateRequest.Address` now use `*UserAddress` instead of `*Address`; `UserRefreshSuccessResponse` removes the exported `Success` field and `SetSuccess` method in favour of a read-only `Success() bool` accessor; and `BookPscAppointment` now requires `*LabTestsBookPscAppointmentRequest` instead of `*AppointmentBookingRequest`.
* The SDK now includes types for lab test compendium search and cross-lab provider ID conversion. New types include `SearchCompendiumBody`, `ConvertCompendiumBody`, `SearchCompendiumResponse`, `ConvertCompendiumResponse`, `CanonicalCandidate`, `PerLabCandidate`, `RelatedCandidate`, `ProviderIdConversionResponse`, along with the `CompendiumSearchLabs` and `SearchMode` enums.
* The SDK now includes two new API client packages: `compendium` (with `Search` and `Convert` methods) and `labaccount` (with `GetTeamLabAccounts`). New supporting types `ClientFacingLabAccount`, `GetTeamLabAccountsResponse`, `LabAccountDelegatedFlow`, `LabAccountStatus`, and `UsState` are also available. The `insulin_pump` source type has been added to ECG and menstrual cycle source type enumerations.
* The SDK now includes a new `ordertransaction` package with a `Client` that supports fetching order transactions, lab results, and lab result PDFs via `GetTransaction`, `GetTransactionResult`, and `GetTransactionResultPdf`. New types `GetOrderTransactionResponse` and `OrderSummary` are also available. Additionally, a new `insulin_pump` source type has been added to the `ClientFacingSleepCycleSourceType` enum.
