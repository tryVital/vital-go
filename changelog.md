## v2.0.0 - 2026-04-02
* The `GetWheelchairUse()` accessor method has been removed from both `ClientFacingActivity` and `ClientFacingProfile`. Callers using these methods will encounter compile errors and should update their code to access the `WheelchairUse` field directly.
* The SDK now supports three new query expression types: `DerivedReadinessColumnExpr` (with a full `DerivedReadinessColumnExprDerivedReadiness` enum), `AwakeningsValueMacroExpr`, and `InsulinInjectionTimeseriesExpr`. The `InsulinInjection` timeseries variant has been promoted from an `IntervalTimeseriesExpr` enum value to its own dedicated expression type, and the `IntervalTimeseriesExprTimeseriesInsulinInjection` constant has been removed.
**Breaking change for interface implementors:** `AggregateExprArgVisitor`, `QueryGroupByItemVisitor`, and `QuerySelectItemVisitor` each have three new required methods (`VisitDerivedReadinessColumnExpr`, `VisitAwakeningsValueMacroExpr`, `VisitInsulinInjectionTimeseriesExpr`). Any type that implements these interfaces must be updated to add the new methods. Additionally, `Placeholder.GetPlaceholder()` has been replaced by `Placeholder.Placeholder()` and the `IntervalTimeseriesExprTimeseriesInsulinInjection` constant has been removed.
* **Breaking changes to `ParsingJob` and `ResultMetadata` types:**
* `ParsingJob.JobId` field along with `GetJobId()` and `SetJobId()` have been removed. A new `FailureReason` field of type `*ParsingJobFailureReason` has been added, with a new `ParsingJobFailureReason` enum (`invalid_input`, `low_quality`, `not_english`).
* `BodyCreateLabReportParserJob.File` has changed from `io.Reader` to `[]io.Reader` to support multiple files per job.
* `ResultMetadata` fields `PatientFirstName`, `PatientLastName`, `Dob`, and `LabName` have changed from `string` to `*string` (now optional); their corresponding getters and setters have been updated accordingly.
* A new `Gender` field (`*ResultMetadataGender`) has been added to `ResultMetadata`, along with a new `ResultMetadataGender` enum (`male`, `female`, `other`).
* The SDK now supports Sonora Quest as a lab partner (`AppointmentProviderSonoraQuest`, `ClientFacingLabsSonoraQuest`). Several new fields have been added across request and response types, including appointment notes, async booking confirmation, order transaction ID filtering, PSC appointment idempotency key support, and access notes for addresses. Note: the types `BiomarkerResult`, `ClinicalInformation`, `LabResultsMetadata`, `LabResultsRaw`, `MissingBiomarkerResult`, `OrderLowLevelStatus`, `ParentBiomarkerData`, `SampleData`, `UtcTimestampWithTimezoneOffset`, `FailureType`, `ResultType`, and related union types have been removed from the public API.
* Several breaking changes have been made to bulk connection operation request types. The `TeamId` field and `SetTeamId` method have been removed from `BulkExportConnectionsBody`, `BulkImportConnectionsBody`, `BulkPauseConnectionsBody`, `BulkTriggerHistoricalPullBody`, and `LinkListBulkOpsRequest`. The exported types `LinkBulkExportRequestTeamId`, `LinkBulkImportRequestTeamId`, `LinkBulkPauseRequestTeamId`, `LinkBulkTriggerHistoricalPullRequestTeamId`, and `LinkListBulkOpsRequestTeamId` have also been removed — callers referencing these types or fields must remove those usages.
* New additions include a `RecoveryReadinessScore` field on `ClientFacingSleep` (sourced from Oura, Whoop, and Ultrahuman), new `VitalIosSdkVersion`, `VitalAndroidSdkVersion`, and `GrantedPermissions` fields on `ManualConnectionData`, a new `samsung_health` value for `ManualProviders`, and a new `tandem_source` value for `PasswordProviders`.
* The SDK now includes new types for lab report parsing job webhook events (`ClientFacingLabReportParsingJobCreatedEvent`, `ClientFacingLabReportParsingJobUpdatedEvent`) and order transaction tracking (`ClientFacingOrderTransaction`, `ClientFacingOrderInTransaction`). New fields have been added to `ClientFacingOrder` (`ClinicalNotes`, `LastEvent`, `Origin`, `OrderTransaction`), `ClientFacingOrderEvent` (`StatusDetail`), `Address` and patient address types (`AccessNotes`). Structured lab result types (`BiomarkerResult`, `LabResultsRaw`, `MissingBiomarkerResult`, `PerformingLaboratory`, `SampleData`) are also now available.
* The SDK now includes three new sub-clients: `Compendium`, `LabAccount`, and `OrderTransaction`, accessible directly from the top-level client. `ClientFacingInsulinInjectionSample` gains optional `DeliveryMode`, `DeliveryForm`, and `BolusPurpose` fields with corresponding enum types. The `Address` type in `UserInfo` and `UserInfoCreateRequest` has been replaced with a new `UserAddress` type — callers using `GetAddress()` or `SetAddress()` must update to use `*UserAddress`. The `BookPscAppointment` method now accepts `*LabTestsBookPscAppointmentRequest` instead of `*AppointmentBookingRequest`, and `ParserCreateJob` now accepts a slice of files rather than a single file.
* The SDK now includes types for the lab compendium search and conversion APIs. New types include `SearchCompendiumBody`, `ConvertCompendiumBody`, `SearchCompendiumResponse`, `ConvertCompendiumResponse`, `CanonicalCandidate`, `PerLabCandidate`, `RelatedCandidate`, `ProviderIdConversionResponse`, `CompendiumSearchLabs`, and `SearchMode`.
* The SDK now includes two new API clients: `compendium` (with `Search` and `Convert` methods) and `labaccount` (with `GetTeamLabAccounts`). New types `ClientFacingLabAccount`, `GetTeamLabAccountsResponse`, `LabAccountDelegatedFlow`, `LabAccountStatus`, and `UsState` are available in the root package. Existing source-type enums for ECG and menstrual cycle data now include the `insulin_pump` variant.
* The SDK now includes a new `ordertransaction` package with a `Client` that exposes three methods — `GetTransaction`, `GetTransactionResult`, and `GetTransactionResultPdf` — for interacting with the `/v3/order_transaction` API endpoints. Two new types, `GetOrderTransactionResponse` and `OrderSummary`, have been added to support these operations. A new `Bytes` pointer helper and the `insulin_pump` source type constant for `ClientFacingSleepCycleSourceType` are also now available.
