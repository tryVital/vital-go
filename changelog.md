## v2.0.0 - 2026-03-27
* The SDK now supports querying derived readiness data and insulin injection timeseries. New `DerivedReadinessColumnExpr` enables access to recovery scores, stress scores, strain metrics, and related readiness data. New `InsulinInjectionTimeseriesExpr` provides dedicated support for insulin injection events with delivery mode and bolus purpose fields.
* The SDK now includes failure reason information for parsing jobs through the new `ParsingJobFailureReason` enum. The `ResultMetadata` struct has been updated with improved field typing, making previously required fields optional and adding a new `Gender` field with enum support.
* The SDK now supports appointment notes for booking and rescheduling appointments, enhanced lab test creation with lab account management fields, and improved order tracking with transaction IDs. New address access notes fields enable better delivery coordination for lab orders and appointments.
* The SDK now supports Samsung Health and Tandem Source providers. New fields `VitalIosSdkVersion`, `VitalAndroidSdkVersion`, and `GrantedPermissions` are available in manual connection data for enhanced tracking capabilities.
* The SDK now supports insulin pump devices with enhanced insulin injection sample data including delivery modes, forms, and bolus purposes. New client modules are available for lab account management (LabAccount), test compendium access (Compendium), and order transaction handling (OrderTransaction). PSC appointment booking now supports idempotency headers for safer operation retries.
* New type definitions for compendium search and lab test conversion functionality. The SDK now includes types for searching lab tests across providers and converting provider IDs between different lab systems.
* The SDK now includes two new client modules: `compendium` for health data search and conversion operations, and `labaccount` for managing team laboratory accounts. New API endpoints are available for searching health data compendium, converting data formats, and retrieving lab account information with filtering by status and account ID.
* New order transaction management capabilities available through the `ordertransaction.Client`. This includes methods to retrieve transaction details, lab results, and PDF reports. The SDK also adds support for insulin pump as a sleep cycle source type.
