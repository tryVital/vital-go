## v2.0.0 - 2026-03-27
* The SDK now supports derived readiness column expressions for accessing readiness metrics like sleep score, recovery score, stress score, and strain score. Additionally, a new insulin injection timeseries expression is available for diabetes management tracking, with support for delivery mode, bolus purpose, and injection values. These new expression types can be used in query aggregation, grouping, and selection operations.
* The SDK now supports enhanced lab report parsing with failure reason detection and improved metadata handling. New failure reasons (invalid_input, low_quality, not_english) provide better error context. Result metadata fields are now optional and include gender support. Multiple file uploads are now supported for parser jobs.
* The SDK now supports asynchronous appointment booking confirmation with configurable timeout settings. New appointment notes functionality is available across booking, rescheduling, and appointment management endpoints. Added support for Sonora Quest lab provider and enhanced filtering options including lab slug and order transaction ID filters.
* The SDK now supports Samsung Health as a manual provider and Tandem Source as a password provider. Enhanced JSON serialization includes new SDK version tracking fields and granted permissions support in manual connection data.
* The SDK now supports enhanced insulin injection data with new delivery mode, form, and purpose fields. A new UserAddress type is available for managing user addresses, replacing the generic Address type. Three new client modules are included: Compendium, LabAccount, and OrderTransaction. The SDK also adds support for insulin pump devices and improved file upload capabilities.
* New compendium types added for laboratory test search and conversion operations. The SDK now includes comprehensive data structures for working with medical laboratory test data, including candidate matching, provider conversion, and cross-laboratory test mapping functionality.
* New compendium functionality for searching and converting data, and lab account management capabilities for retrieving team lab account information. The SDK now includes insulin pump as a supported data source type for electrocardiogram and menstrual cycle data.
* New order transaction management capabilities added, including methods to retrieve transaction details, results, and PDF reports. The SDK also now supports insulin pump as a source type for sleep cycle data.
