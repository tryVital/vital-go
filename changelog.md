## v2.0.0 - 2026-03-31
* The SDK now supports derived readiness metrics and dedicated insulin injection timeseries queries. New capabilities include querying chronotype, sleep scores, recovery zones, stress scores, strain metrics, and detailed insulin delivery tracking with bolus purpose and delivery mode fields. The QueryBatch type now requires timeframe and queries fields to be explicitly set.
* The SDK now supports detailed failure reasons for parsing jobs through the new `ParsingJobFailureReason` enum. Lab report metadata has been enhanced with an optional gender field and all metadata fields are now optional pointers for better null handling.
* New appointment booking features including idempotency support, appointment notes, and async confirmation capabilities. Added Sonora Quest lab support and several new optional fields for enhanced lab test ordering and patient data management.
* Breaking changes: The `TeamId` field has been removed from `BulkExportConnectionsBody`, `BulkImportConnectionsBody`, `BulkPauseConnectionsBody`, `BulkTriggerHistoricalPullBody`, and `LinkListBulkOpsRequest` structs. Code referencing these fields must be updated. Several optional fields are now required: `Address` in `CreatePayorBody`, `ShippingDetails` in `CreateRegistrableTestkitOrderRequest`, and `PatientDetails`/`PatientAddress` in `RegisterTestkitRequest`. New features include Samsung Health and Tandem Source provider support, plus new SDK version tracking fields in `ManualConnectionData`.
* The SDK now supports insulin pump devices and enhanced insulin injection data including delivery modes (basal/bolus), delivery forms (standard/extended), and bolus purposes (meal/correction/mixed/unknown). User address handling has been improved with a dedicated UserAddress type. New client modules are available: Compendium, LabAccount, and OrderTransaction for expanded API functionality.
* The SDK now includes comprehensive type definitions for the Vital Compendium API, enabling lab test search, provider ID conversion, and biomarker canonicalization across different laboratory networks.
* New Compendium client with Search() and Convert() methods for laboratory data processing. New LabAccount client with GetTeamLabAccounts() method for managing team laboratory accounts. Added insulin_pump source type support for electrocardiogram and menstrual cycle data.
* New OrderTransaction client provides methods to retrieve transaction details, lab results, and PDF downloads. Added insulin_pump as a new sleep cycle source type option.
