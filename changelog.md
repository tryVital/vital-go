## v2.0.0 - 2026-03-30
* The SDK now supports derived readiness column expressions and insulin injection timeseries expressions in query operations. New capabilities include querying readiness metrics (recovery scores, strain zones, sleep scores) via `DerivedReadinessColumnExpr` and insulin injection data via `InsulinInjectionTimeseriesExpr`.
* The SDK now supports parsing job failure reasons through the new `ParsingJobFailureReason` enum, providing better insight into why lab report parsing may fail. Additionally, `ResultMetadata` fields are now optional pointers for more flexible data handling, and a new `Gender` field has been added to capture patient gender information.
* New appointment booking features with asynchronous confirmation support, appointment notes, and Sonora Quest lab provider integration. Additional fields added to lab test creation, order requests, and address types for enhanced functionality.
* Breaking changes to bulk operation request types: removed TeamId fields from BulkExportConnectionsBody, BulkImportConnectionsBody, BulkPauseConnectionsBody, BulkTriggerHistoricalPullBody, and LinkListBulkOpsRequest. Several previously optional fields are now required: UserIds in bulk pause and trigger operations, Connections in bulk import, Address in payor creation, and address/details fields in testkit requests. Code using TeamId fields must be updated to remove those references, and code relying on optional field behavior must ensure required fields are provided.
* The SDK now supports enhanced insulin injection tracking with delivery mode, delivery form, and bolus purpose fields. New client modules are available for Compendium, Lab Account, and Order Transaction functionality. The insulin pump device source type is now supported for comprehensive diabetes management tracking.
* The SDK now supports compendium API functionality with new types for lab test searching and provider ID conversion. New types include ConvertCompendiumBody, SearchCompendiumBody, CanonicalCandidate, PerLabCandidate, and related response structures for working with laboratory test data across different providers.
* New compendium API support for food and exercise data operations with Search() and Convert() methods. Added lab account management functionality with GetTeamLabAccounts() method. The "insulin_pump" source type is now available for electrocardiogram and menstrual cycle data.
* New OrderTransaction client available with methods to retrieve transaction details, results, and PDF reports. Added support for insulin pump as a sleep cycle data source type.
